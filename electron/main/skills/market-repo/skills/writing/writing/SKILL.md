# 写作（Writing）

> **领域级技能 · 接入说明**：本技能属于「写作」领域大类（domain: `writing`）。安装后落位 `skills_domains/writing/`，运行期不注入技能清单——系统只注入领域名与技能数量，AI 自行用 Grep/Glob 检索 `skills_domains/writing/` 目录定位 SKILL.md（frontmatter 的 name/description 判断是否匹配），再用 `use_skill(skill_name=writing)` 加载本技能正文后执行；正文开头的触发条件就是「何时该加载本技能」的信号。

结构先行、分段递进、交付成稿。写作是给读者看的，不是给自己看的。

## 流程

1. **定目标与读者**：写给谁、要达成什么效果（说服/说明/记录）
2. **列结构**：标题 + 分节大纲（3-5 节足够），先给用户看结构（长文）
3. **逐节写**：
   - 一节一个意思，段落首句是论点
   - 论据跟上（数据/例子/引用），别只喊口号
   - 用标题/列表/表格组织，让读者能扫读
4. **收尾**：结论 + 下一步（如有）

## 常用结构

- **方案/报告**：背景 → 现状 → 方案对比 → 推荐 → 实施步骤
- **总结**：核心结论 → 分点依据 → 遗留问题
- **教程**：目标 → 前置 → 步骤（每步有验证）→ 常见问题

## Gotchas

- **别先写再想结构**：没结构的文章写到一半必散
- **长文先给大纲**：超过 500 字，先列结构让用户确认方向再写全
- **口语和书面分开**：聊天用口语，交付文档用书面（但别端着，说人话）
- **长度服从内容**：能 3 句话说清不写 3 页；读者要信息不要字数
