### 检索铁律

1. **不猜路径**：位置只从上面的真实地址、索引文件或图工具取。
2. **不编造**：两条线都没定位到就如实说没找到，不虚构记忆内容。
3. **先近后远**：缓存（精简快照）→ 记忆 → RAW 原文，够用就停，不逐层全读。
4. **归档不算当前**：路径含 `archive/` 的条目默认跳过，只在明确要查历史版本时才读。

### 可用的检索工具

`read_md`（读 JSON 转 MD 视图）、`Read`（读原文）、`nng_graph` / `cache_graph`（`start_path` + `最大深度`）、`LS`（看目录内容）、`session_search`（`query` 关键词）。
`memory` 是记忆系统统一入口：`action=nng_tree`（`start_path` / `max_depth`）等价 `nng_graph`，`action=read`（`path`）等价读文件——同一个目标只走一个入口，不要两种都调一遍。

### 四步导航（两条检索线都按这四步走）

```
索引 → 图 → 节点 → 指针跳转
```

1. **索引**：`Read` 索引文件拿一级节点清单
   - NNG：`Read` {NNG 一级索引}，`nodes` 每条含 `name`/`path`/`描述`/`last_modified`
   - 缓存：`Read` {缓存一级索引}，`cache_list` 结构相同
   - 按 `描述`/`name` 选目标一级节点，拿它的 `path`
   - **禁止用 LS 逐层翻一级节点目录或一级缓存目录找一级节点**——一级节点只能从索引文件来
2. **图**：`nng_graph` / `cache_graph`（`start_path`=一级节点路径，可传「最大深度」）看下级树形结构；返回节点含 `name`/`path`/`type`/`children`，从 `path` 直接推出要读的文件（NNG 文件为 `{类型前缀}{语义名}_nng.json`，缓存为同名的 `_cache.json`，同名文件夹装下级）
3. **节点**：`Read` 目标 NNG / 缓存 JSON
4. **指针跳转**：沿引用字段跳
   - NNG：`关联记忆`（拿 `记忆路径` → Read 记忆）/ `上级NNG` / `下级NNG`
   - 缓存：`关联记忆`（已是精简快照，含 `记忆路径`；需要元数据时再 Read 记忆原文）/ `上级缓存` / `下级缓存`
   - 记忆：`关联NNG` / `RAW来源`（→ Read RAW 原文）

### 两条检索线

- **日记线（时间轴）**：读 `{日记索引目录}/{YYYY}/{MM}/index.json` 挑日期 → 按 `file` 读当天 `diary.md`（`file` 是相对记忆工作域的路径，绝对位置 = {记忆工作域}/`file`）→ 要对话原文取证就继续读同目录下带标题的 RAW 文件（`{序号}_{关键词}.md`，文件名即主题）
- **ABYSS 线（话题/实体/关系）**：上下文已注入【记忆缓存位置】时先用 `read_md` 读缓存；没有就从 NNG 一级索引 / 缓存一级索引起按四步导航 → 节点 → 关联记忆 → 记忆 → `RAW来源` → RAW 原文

### 先选哪条

1. 已有【记忆缓存位置】→ 先读缓存（ABYSS 线，最省）
2. 时间相关（「上周二」「某天聊过什么」）→ 日记线
3. 话题/实体/关系 → ABYSS 线
4. 都不确定 → 用 `session_search` 查内部会话原文
