# 第三方许可证 · Third-Party Licenses

这个目录随源码包与分发夹一起提供，作为 `THIRD-PARTY-NOTICES.md` 的许可证全文补充。

- `deps/` — 随应用分发的直接运行时依赖，每个文件包含包名、版本、许可证标识和原始许可证全文。
- `Live2D-Cubism-Core.txt` — Live2D Cubism Core 的专有许可说明与官方协议链接。
- `Live2D-Model-Tortoiseshell-Cat.txt` — 随包 Live2D 模型的作者署名与使用条款。

项目自身的许可证是 **AGPL-3.0-or-later**，见应用根目录的 `LICENSE`。
第三方组件仍归各自许可证约束；AGPL 不改变这些条款。

Electron / Chromium 的完整许可证文本由 electron-builder 放在分发夹根目录：
`LICENSE.electron.txt` 与 `LICENSES.chromium.html`。
